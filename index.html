Client Name and Build Version go in the HTTP headers (apollographql-client-name, apollographql-client-version). Apollo Package and Apollo Version go in the extensions.clientLibrary JSON. All values are saved in your browser's local storage.

How to call these endpoints

All operations use GET requests with Apollo Automatic Persisted Queries. Each operation card has a live Request Builder: edit parameter values, toggle optional parameters on/off, then copy the generated URL or fetch() snippet. Authenticated requests must be run from a logged-in lolesports.com browser session (credentials: "include" sends your cookies).

Set your Client Name and Build Version in Request Settings above — the generated fetch() code uses them in the headers and clientLibrary extension.

Queries vs mutations: QUERY operations only read data — safe to call. MUTATION operations write data (registering, submitting picks, joining, updating, deleting) and require a logged-in session; calling one has real side effects on your account. Use the All / Queries / Mutations filter below to view them separately.
